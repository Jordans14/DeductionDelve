## Role Philosophy
Roles exist to shape physical ambiguity, not to replace it. The game remains traversal-first and pressure-first; roles modify what counts as plausible, suspicious, burdensome, or opportunistic inside that physical space.

## Current Live Roles
- Warden
- Steward
- Bearer
- Veil
- Murmur
- Scavenger

These roles are the current live implementation and remain on one lawful role owner path.
- `Warden`, `Steward`, `Bearer`, and `Scavenger` are expedition-aligned roles with different custody, witness, rescue, and burden pressures.
- `Veil` and `Murmur` are sabotage-aligned roles with different forgery, witness-distortion, and ambiguity pressures.
- The live player-count bands now expand into this roster deterministically rather than holding the repo to the old three-role baseline.

## Deception Model
Deduction should come from:
- movement
- burden handling
- rescue or non-rescue
- route choice
- hesitation
- confrontation timing
- object handling
- extraction behavior

Not from:
- abstract meetings
- hard-proof accusation systems
- non-diegetic social minigames

## Future-Phase Design Context
The finalized Delve Protocol doctrine expands the world around these roles through:
- relay recombination
- branch ideology
- Archive comparison
- world fascination
- protocol states

That broader frame should deepen role interpretation rather than replacing the current role owner path.
