# Cookbook System

See also: [THE_DELVE_PROTOCOL](d:/DeductionDelve/docs/THE_DELVE_PROTOCOL.md), [NARRATIVE_WORLD_BIBLE](d:/DeductionDelve/docs/NARRATIVE_WORLD_BIBLE.md), [ARCHIVE_SYSTEM](d:/DeductionDelve/docs/ARCHIVE_SYSTEM.md).

## Cookbook Concept
The Delve Anarchist's Cookbook is a forbidden body of anti-Protocol knowledge. It is not a normal item, not a simple codex entry, and not a public upgrade track.

## Fragment Discovery
Cookbook knowledge appears through fragments:
- anomaly-linked discoveries
- post-core echoes
- repeated impossible pattern inversions
- rare Archive tensions that do not fit public explanations

## Cookbook Holders
Cookbook holders are not a formal faction. They are a hidden network of players who have begun recognizing ways to break or redirect Protocol expectations.

## Marginalia System
Cookbook fragments accumulate through marginalia:
- notes
- revisions
- contradictions
- anti-Protocol interpretations of known branch, item, and crawl stories

## Cookbook Network
The Cookbook network is a hidden continuity layer joining rare holders through shared anomaly patterns, indirect recognition, and relay-era rumor.

## Anti-Protocol Descent
At its deepest implementation target, the Cookbook enables descents that are no longer purely compliant with the Delve's intended pressures. This is not ordinary progression power. It is a rare narrative and systems endgame.

## Experiment Collapse Event
The most extreme future-phase outcome is not a simple win state. It is a collapse event where the Delve's own framing becomes unstable because too many anti-Protocol reads, fragments, and holders align.

## Current Live Implementation Note
The live repo now implements hidden Cookbook continuity through profile, world-memory, and Delve-intake state: fragment accumulation, holder depth, network rumor, and redirection pressure all persist through the existing read-only product path. Anti-Protocol descent and collapse-event endgame behavior remain the deeper extension target on that same owner tree rather than a separate narrative system.
