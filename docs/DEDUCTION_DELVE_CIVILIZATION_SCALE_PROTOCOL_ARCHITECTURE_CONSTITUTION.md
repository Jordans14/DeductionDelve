This document is the final and sole constitutional architecture for the project.

It defines:

- what the game is
- what the system may and may not become
- who owns truth
- who owns simulation authority
- how DelveMind is bounded
- how the world evolves
- how culture, institutions, and civilization emerge
- what Codex may and may not implement
- how all derivative specifications must be written

No other document may override it.

## 1.2 Scope
This constitution governs:

- engine-space architecture
- protocol-space architecture
- expedition simulation
- civilization simulation
- public-shell doctrine
- DelveMind governance
- repository authority cleanup
- implementation safety

## 1.3 One-document rule
A Codex planning or implementation pass must be able to read **this file alone** and recover the full architectural system without needing another architectural constitution.

Support docs may still exist for subsystem detail, examples, or implementation convenience, but they are subordinate and explanatory, not sovereign.

# 3. SACRED DESIGN ANCHOR

## 3.1 Primary identity
The Delve Protocol is a:

- traversal-first
- pressure-first
- extraction-first
- socially interpreted
- historically accumulating
- culturally remembering
- experiment-shaped labyrinth game

## 3.2 Story source
Story comes from physical play:

- movement
- carrying
- dropping
- rescuing
- losing
- hesitating
- routing
- extracting
- failing
- returning

## 3.3 Meaning source
Meaning comes from the interaction between:

- expedition truth
- public interpretation
- institutional memory
- DelveMind experimental shaping
- civilizational disagreement

## 3.4 What the game must never become
The game must never become:

- a detached voting game
- a mission-board MMO hub
- a lore-wiki-first browser
- a codex wall
- a meeting simulator
- a combat-heavy action game
- a second-shell narrative browser
- a second runtime authority stack
- a second truth model
- a human-GM runtime replacement
- a perfectly knowable optimization machine

## 3.5 Permanent mystery law
The labyrinth must remain fundamentally not-fully-solvable.

The game may deepen understanding.
It may never collapse into total explanation.

## 4.1 Traversal generates story
Physical traversal remains the primary story generator.

## 4.2 Run truth is absolute

## 4.3 Product is read-only relative to run truth

There is one shell path, not multiple detached narrative or management browsers.

## 4.7 Determinism law
Authoritative gameplay must remain deterministic and testable.

## 4.8 Civilization must route back into play
Every civilizational layer must eventually change embodied expedition behavior.
