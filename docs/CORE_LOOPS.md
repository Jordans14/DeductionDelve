# Core Loops

See also: [MECHANICS](d:/DeductionDelve/docs/MECHANICS.md), [ARCHIVE_SYSTEM](d:/DeductionDelve/docs/ARCHIVE_SYSTEM.md), [CRAWL_NETWORK_ARCHITECTURE](d:/DeductionDelve/docs/CRAWL_NETWORK_ARCHITECTURE.md).

## Run Loop
1. The host reads session/gameplay context plus host-local continuity and computes a Delve directive for the next run.
2. Enter a deterministic branch-contextual run node.
3. Traverse hazards, route choices, burden pressure, and social ambiguity.
4. Read movement, hesitation, rescue, refusal, confrontation, and extraction pressure as narrative signals.
5. Finish with extraction, interruption, collapse, or unresolved pressure.

## Run Authoring Loop
1. The host kernel computes a deterministic Primal Force profile from continuity, session context, and seed.
2. Active minds interpret that force profile, receive temporary roles, and shape bounded domains such as topology, pacing, pressure grammar, item ecology, and symbolic language.
3. Existing owners consume the resulting control surfaces, run-identity summary, and public-safe domain/archive/item-ecology summaries without surrendering run authority.
4. The shell and Archive later carry forward only the public-safe part of that authored identity.

## Crawl Loop
1. A run contributes to an active crawl.
2. The crawl accumulates pressure, heat, residue, open questions, remembered pair/crew history, artifact echo, and branch reputation drift.
3. Players decide whether to stabilize, bank, push deeper, or return to the same pressure later.
4. The crawl gains identity through repetition, breakage, inversion, memory, and compact comparison against prior runs.

## Archive Loop
1. The run becomes a case.
2. The Archive compares it against prior echoes and current fascination using stored run facts plus public-safe doctrine/governance carryover, branch-drift cues, and compact artifact-lineage signals.
3. The shell surfaces what happened, what pattern matters, and what to watch next.
4. Later runs inherit that cultural pressure.

## World Loop
1. Stories accumulate around branches, items, crawls, pairs, crews, and players.
2. Fascination heats, spreads, cools, revives, and reorients.
3. Commentary, crawl memory, and Archive framing make the world feel like it remembers through compact signals rather than lore walls.
4. New descents happen inside that remembered cultural weather.
