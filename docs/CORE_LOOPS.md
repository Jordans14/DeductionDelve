# Core Loops

## 30-Second Loop (Micro)
1. Enter a room and read traversal risk (hazards, enemy pathing, trap states).
2. Coordinate movement and utility use while watching non-verbal tells.
3. Secure loot/evidence or trigger a tactical retreat.
4. Update suspicion mentally or in notebook from what happened and who had opportunity.

## 3-Minute Loop (Encounter Cluster)
1. Clear 2-4 rooms with mixed cooperation and role-driven friction.
2. Spend scarce resources (heals, keys, utility charges) under uncertainty.
3. Observe possible sabotage accidents (trap trigger timing, forced misroutes, bait pings).
4. Trade, hide, forge, or contest evidence artifacts.
5. Re-group at checkpoint vendor/shrine and decide route branch.

## 30-Minute Loop (Full Run)
1. Lobby ready-up selects host seed and starts biome run.
2. Team traverses generated room chain, collecting items and evidence.
3. Suspicion rises as deaths/resource losses occur with plausible deniability.
4. Build synergies unlock new deception/investigation methods.
5. Deterministic run-end trigger fires on host (current v0: tick limit).
6. End screen reveals roles and summary metrics with timeline recap.

## Meta Loop
- Players learn to read map-state plus behavior tells.
- Unlock additional item pools/room variants via account progression.
- Social mastery shifts from "who lies well" to "who manipulates systems cleanly."

## Dependency Between Loops
- Micro traversal creates concrete event facts.
- Encounter clusters contextualize those facts with role incentives.
- Full run resolution interprets facts via incomplete and manipulable information.
