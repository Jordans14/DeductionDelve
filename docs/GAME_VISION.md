# Deduction Delve - Game Vision

## Genre Identity
Deduction Delve is a cooperative extraction platformer where every jump, trap, and loot decision is also social evidence. The same systems that create roguelite chaos also create lies, alibis, and suspicion. Players are never solving deduction outside the run; they are deducing directly through traversal risk, item behavior, and physical evidence.

## Three-Sentence Unique Pitch
In Deduction Delve, evidence is loot: clues are physical objects inside dangerous rooms, so learning the truth requires platforming skill and shared risk. Builds change deception surface, not just combat power, so item RNG determines what lies are believable and which tells leak. The result is a social-deduction roguelite where "accidents" are strategic tools and counter-forensics are part of surviving the run.

## Design Pillars
1. Evidence is loot: truth exists as contestable physical artifacts.
2. Accidents are mechanics: many kills can be plausibly environmental.
3. Buildcraft changes social affordances: movement/noise/visibility modify alibi credibility.
4. Inference over certainty: tools support reasoning, never hard proof.
5. Shared chaos with guardrails: seeded generation and constrained RNG keep runs legible.

## Target Experience
- Player count: 4-8 online.
- Session length: 25-40 minutes.
- Feel: tense co-op platforming with recurring social ruptures.
- Replay value: role uncertainty + seeded layouts + synergy-driven deception styles.

## Success Criteria
- Players can explain suspicious events using both map/hazard context and observed social behavior.
- Role incentives create selective cooperation without forcing instant PvP.
- Post-run timeline supports "I think this happened" debates, not deterministic verdicts.
