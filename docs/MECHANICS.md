## Current Mechanical Identity
The Delve Protocol remains:
- traversal-first
- pressure-first
- extraction-first
- social-deduction-through-physical-play

The live implementation currently centers on host-authoritative traversal, hazards, artifacts, extraction windows, role secrecy, sabotage pressure, deterministic branch personality, expanded item-tool expression, bounded inhabitant ecology, trust/relay/cookbook/civilization routing through the existing owner tree, and product-shell interpretation.

## Current Live Delve Role
- The AI Delve is a pre-run orchestration and interpretation layer, not a runtime truth owner.
- It reads local profile continuity plus session/gameplay context, computes a Primal Force profile, activates multiple interpretive minds, assigns temporary roles, and emits bounded control surfaces plus a run-identity trace for existing owners to consume.
- Today it materially shapes topology, item ecology, pacing identity, symbolic expression, and public-safe post-run doctrine/governance carryover.
- It does not replace player-authored story, own movement/hazards, or grant product memory mechanical authority.

## Pressure Grammar

- compression

- escalation

- scarcity

These verbs influence generation cadence, item ecology, and symbolic interpretation through weighting rather than direct runtime intervention.

## Pacing And Social Deduction
Each run now receives a pacing identity such as `calm`, `steady`, `escalating`, or `volatile`.
- Pacing affects trap rhythm, encounter spacing, and resource cadence through existing owners.
- Group-tension shaping strengthens ambiguous cause, trust fragility, and cooperation strain without overriding player agency.
- The readability budget keeps authored identity legible by limiting how many dominant signals are exposed at once.

## Relay / Crawl-Network Pressure
The live repo now routes relay stress, distributed witness, bottlenecks, rumor heat, and cohort pressure back into:
- branch weighting
- route-stagecraft pressure
- runtime watch cadence
- runtime noise cadence
- extraction return pressure

Full relay recombination and population-scale relay routing remain future-phase.

The live generator and item ecology now use branch-family context plus reduced protocol labels to create clearer deterministic route identity, room mixes, and branch-flavored spawn pressure. That now includes `Oath Terraces` and `Murmur Warrens` rather than only the older five-family set.

## Reduced Protocol-State Pressure
The live repo already uses reduced protocol-state labels to alter interpretation and presentation pressure. Full relay-topology and large-population behavior changes remain future-phase.

## Combat Scaling
Combat remains sparse and pressure-shaped. The live repo now scales bounded inhabitant combat pressure upward as social density drops and protocol state narrows, with predator pursuit/ambush/pack distinction and protocol-watch inspection/containment/interdiction distinction, while keeping combat subordinate to traversal, burden, rescue, and extraction rather than turning into a second action game.
