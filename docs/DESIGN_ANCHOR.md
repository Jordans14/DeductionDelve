# The Delve Protocol - Design Anchor

See also: [THE_DELVE_PROTOCOL](d:/DeductionDelve/docs/THE_DELVE_PROTOCOL.md), [GAME_VISION](d:/DeductionDelve/docs/GAME_VISION.md), [ARCHITECTURE](d:/DeductionDelve/docs/ARCHITECTURE.md).

## Core Statement
The Delve Protocol is a traversal-first social exploration game about remembered descents inside a living labyrinth experiment.

## What Must Stay True
- physical action creates narrative
- AI Delve can shape setup and interpretation, but it cannot replace physical play as the source of story
- product systems interpret rather than replace that narrative
- visual doctrine stays presentation-only and honest about what is reachable or interactive
- the shell remains unified
- run truth stays authoritative
- the Archive remains the cultural memory path
- player-facing language stays Layer-1 safe

## What the Game Should Feel Like
- a remembered expedition culture
- a dangerous crawl mythology engine
- a branch-aware labyrinth with symbolic places
- a world that notices patterns without explaining itself too early

## What the Game Must Not Become
- a detached voting game
- a mission-board MMO hub
- a codex wall
- a cutscene mystery
- a combat-heavy action game
