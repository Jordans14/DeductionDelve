## Roadmap Framing
The live repo already contains the current traversal/network/product shell foundation plus a live AI Delve directive layer and a live visual governance layer. The roadmap below keeps completed near-term work visible, then names the next live frontier without collapsing future-phase canon into current implementation.

## Completed Near-Term Stabilization
1. Delve boundary coverage and consumer discipline
   Status: completed and validated on `2026-03-14`.
   Result: the Delve directive stays bounded inside the current owner tree, clients receive only the public-safe summary, and product layers remain read-only relative to run truth.
2. Visual governance contract enforcement
   Status: completed and validated on `2026-03-14`.
   Result: room packets, doctrine layers, shell motifs, and background honesty are enforced while visual governance remains presentation-only.
3. Product framing and archive truth discipline
   Status: completed and validated on `2026-03-14`.
   Result: Home/Profile/Crawl/Archive consume only public-safe doctrine and governance carryover, with wording guards preventing host-only leakage.

## Completed Near-Term Deepening
1. Deepen live Delve control-surface consumption through existing owners only.
   Status: completed and validated on `2026-03-14`.
   Result: existing host owners now consume control surfaces more deeply for extraction timing, ghost pressure, room shaping, and item ecology while preserving determinism and payload privacy.
2. Deepen branch and reduced protocol-state weighting before relay expansion.
   Status: completed and validated on `2026-03-14`.
   Result: branch families and reduced protocol labels now materially differentiate deterministic room mixes, route identity, and item spawning without introducing a second generation model.
3. Tighten shell explainability around public-safe doctrine carryover.
   Status: completed and validated on `2026-03-14`.
   Result: doctrine/governance carryover is more compact and readable on the existing unified shell path, with no added UI surfaces.

## Completed Ordered Next-Tier Deepening
1. Proof-lane stability hardening
   Status: completed and validated on `2026-03-14`.
   Result: `run_headless_proof.ps1` now detects rare transient pre-verify stalls and retries cleanly instead of hanging.
2. Branch pressure, item ecology, crawl memory, and archive comparison deepening
   Status: completed and validated on `2026-03-14`.
   Result: the live repo now carries stronger deterministic branch personality plus compact artifact-lineage, branch-drift, prestige, and cultural-association signals through the existing generation, item, crawl, archive, and world-memory owners.

## Current Frontier
1. The explicit GenerationContract seam, trust-topology embodiment, relay/crawl-network embodiment, cookbook/anti-Protocol embodiment, civilization-conflict embodiment, role/custody deepening, bounded inhabitant differentiation, player-guidance deepening, role expansion, and the current content-breadth push are now live on the existing owner tree as of `2026-03-15`.
2. The remaining frontier is no longer the basic owner-path embodiment of those systems; it is breadth tuning, authored differentiation, and honest repo auditing inside the same owners without reopening architecture law.
3. Archive/crawl/world-memory interpretation should now deepen only where newly embodied run signals justify stronger comparison, not as a substitute for play-facing consequence.

## Guardrails
- no parallel archive
- no second shell
- no second truth model
- no gameplay power from product memory
- no truth-layer leaks on public surfaces

## Wait Until Later
- Relay nodes and relay recombination at scale
- Full population-adaptive crawl routing
- Broad predator/echo/protocol-agent rosters beyond the current bounded host ecology path
- Cookbook fragments and anti-Protocol descent escalation beyond the current bounded routing seam

These remain canonical future-phase targets. They should land only after the live Delve, visual governance, and product-truth boundaries are more fully stabilized.
