## Crawl Definition
A crawl is the long-form descent arc linking multiple runs into one remembered saga. A crawl is not only a history container; it is a cultural object with identity, pressure, residue, open questions, and public attention.

## Node Types

### Run Nodes
Ordinary descent segments where traversal, burden handling, social deduction, extraction pressure, and confrontation produce the primary story.

### Relay Nodes
Recombination points where player populations from separate lines may be merged, split, or redirected. This is a future implementation phase and should extend the current networking architecture rather than replace it.

### Branch Gates
Directional commitment points into distinct branch ideologies. They are where route, burden, witness, and challenge texture become meaningfully different.

### Echo Chambers
Nodes that amplify cultural memory, prior-run resemblance, and Archive attention.

### Collapse Zones
Destabilized spaces where pressure is high, route certainty is low, and protocol behavior becomes visibly strained.

## Network Graph Structure
The crawl network is a dynamic graph, not a fixed staircase. It should support:
- branch divergence
- relay recombination
- return pressure
- symbolic paths
- remembered gateways
- crawl identity formation through repeated traversal of meaningful node types

## Player Flow Through Nodes
Players move through the network by:
- surviving run nodes
- making branch commitments
- enduring relay shifts
- carrying burdens forward
- creating historical residue that changes how later nodes are read

## Crawl Identity Formation
Crawl identity forms through:
- repeated branch choices
- repeated rescue or confrontation patterns
- item-lineage pressure
- relay recombination effects
- Archive interpretation
- public challenge and fascination pressure

## Current Live Implementation Mapping
The live repo already supports:
- deterministic run generation
- branch-family context in generation
- crawl continuity and world-memory state
- crawl identity recognition through compact artifact echo and branch-drift carryover
- archive comparison and shell continuity on the same product path

Future phases deepen this into:
- explicit relay nodes
- richer crawl graph routing
- protocol-state-driven node behavior
- post-core crawl reinterpretation
